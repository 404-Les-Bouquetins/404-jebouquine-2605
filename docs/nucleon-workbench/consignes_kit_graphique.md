Présentation du kit graphique d'un projet

## Objectif pédagogique

À l'issue de ce travail, vous serez capable de concevoir et réaliser une page web présentant l'identité visuelle complète d'un projet numérique.

## Contexte professionnel

Vous intégrez une agence web chargée de développer un nouveau projet numérique pour un client.

Avant le démarrage du développement, l'équipe a besoin d'une page web de référence regroupant l'ensemble du kit graphique afin de garantir la cohérence visuelle du projet.

## Consignes

### 1. Structure de la page

Créer une page HTML présentant les éléments suivants :

1. Le nom du projet.
2. Le logo principal.
3. Une courte description du projet.
4. Une navigation permettant d'accéder rapidement aux différentes sections.

### 2. Palette de couleurs

Créer une section dédiée aux couleurs du projet.

Pour chaque couleur, afficher :

- Un aperçu visuel.
- Le nom de la couleur.
- Le code HEX.
- Le code RGB.

Minimum :
- 1 couleur principale.
- 2 couleurs secondaires.
- 1 couleur d'accentuation.

### 3. Typographie

Présenter les polices utilisées dans le projet.

Pour chaque police :

- Nom de la police.
- Exemple de titre.
- Exemple de texte courant.
- Type d'utilisation (titres, contenu, boutons, etc.).

### 4. Boutons et composants

Créer une section contenant :

- Bouton principal.
- Bouton secondaire.
- Bouton désactivé.
- Champ de formulaire.
- Carte (card).

Chaque composant doit respecter la charte graphique définie.

### 5. Icônes et visuels

Présenter :

- Les icônes principales utilisées.
- Les illustrations ou images de référence.
- Les règles d'utilisation éventuelles.

### 6. Responsive Design

La page doit être utilisable sur :

- Mobile.
- Tablette.
- Desktop.

Utiliser :

- Flexbox.
- CSS Grid.
- Media Queries.

### 7. Accessibilité

Respecter les bonnes pratiques :

- Contraste suffisant.
- Balises HTML sémantiques.
- Texte alternatif sur les images.
- Navigation clavier fonctionnelle.

## Livrables attendus

Dans le répertoire `src`, créer un dossier `assets`.

Dans ce dossier, créer et implémenter :

1. Un fichier `kit-votre-nom.html`.
2. Un fichier `kit-votre-nom.css`.

## Critères de réussite

### Réalisation technique

- Structure HTML valide.
- CSS organisé et lisible.
- Responsive Design fonctionnel.
- Respect des conventions de nommage.

### Qualité visuelle

- Cohérence graphique.
- Hiérarchie visuelle claire.
- Présentation professionnelle.

### Accessibilité

- Bon contraste.
- Navigation clavier.
- Respect des balises sémantiques.

## Bonus
